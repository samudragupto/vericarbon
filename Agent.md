## Core domain semantics
NOTE: the issuance/claim nullifier definitions below were amended by AMENDMENT A0 (see
Amendments). Where they conflict, Amendments win.
- geoCommitment := keccak256(abi.encode(geohash8, salt))  // client salt, disclosed in the
  IPFS evidence bundle; after A0 used ONLY to link registration to issuance.
- issuanceNullifier := keccak256(abi.encode(geohash8, vintageYear, creditType))
  // A0: salt-INDEPENDENT and registry-INDEPENDENT. Same land+vintage+type in ANY two
  // registries collides -> revert. This unicity is the headline guarantee.
- claimNullifier := keccak256(abi.encode(issuanceNullifier, claimant, claimType,
  beneficiaryCommitment)); recorded once at retirement; replay reverts.
- Issuance requires a valid ezkl proof; public inputs [modelHash, dataCommitment,
  claimedAmount]; statement: claimedAmount <= model(preimage(dataCommitment)) in fixed
  point; binding via the ezkl Poseidon path (NOT in-circuit SHA-256 — that is an off-chain
  audit pointer in the IPFS bundle only).
- creditType: contract enum {REMOVAL, REDUCTION} (A0). vintageYear bounds-checked
  2000..current year (A0).

## Amendments
### AMENDMENT A0:
1. `geoCommitment := keccak256(abi.encode(geohash8, salt))`. Kept at `registerProject` for client-side plot privacy before issuance, and disclosed in evidence bundle.
2. `issue()` signature changes: requires `geohash8` and `salt` as explicit calldata (in addition to `projectId`). Contract asserts `keccak256(abi.encode(geohash8, salt)) == projects[projectId].geoCommitment`.
3. `issuanceNullifier := keccak256(abi.encode(geohash8, vintageYear, creditType))`. It is salt-INDEPENDENT and registry-INDEPENDENT. The salt CANNOT be used to dodge nullification.
4. `creditType` is a Solidity enum `{ REMOVAL, REDUCTION }`, not a string.
5. `vintageYear` is `uint16`, constrained: `2000 <= vintageYear <= currentYear` (via `block.timestamp` year derivation).
